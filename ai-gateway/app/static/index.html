Cấu Hình Kết Nối Backend (Upstream)

Domain tĩnh ngrok trỏ về llama.cpp server đang chạy trên Google Colab. Bạn có thể cập nhật địa chỉ này trực tiếp bất kỳ lúc nào mà không cần restart gateway.

Ví dụ: https://my-llama.ngrok-free.app/v1 (có /v1 ở cuối)
💡 Gợi ý lệnh chạy llama.cpp server trên Colab kèm ngrok:
# Chạy llama.cpp server trên port 8080:
./llama-server -m model.gguf -c 4096 --port 8080 --host 0.0.0.0

# Mở ngrok domain tĩnh miễn phí trỏ tới port 8080:
ngrok http 8080 --domain=ten-domain-cua-toi.ngrok-free.app
